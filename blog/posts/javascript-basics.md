JavaScript is one of the most popular programming languages in the world, and for good reason! Let's dive into the basics.

## What is JavaScript?

JavaScript is a versatile programming language that runs in web browsers, making websites interactive and dynamic. It's also used on servers with Node.js.

## Your First JavaScript Code

Here's a simple "Hello, World!" program:

```javascript
console.log("Hello, World!");
```

## Variables

Variables store data that you can use later:

```javascript
let name = "Randan";
const year = 2026;
var isLearning = true;
```

### Key Differences:
- `let`: Can be reassigned
- `const`: Cannot be reassigned (constant)
- `var`: Old way (avoid in modern code)

## Functions

Functions are reusable blocks of code:

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("Developer")); // Output: Hello, Developer!
```
